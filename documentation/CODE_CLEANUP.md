# Code cleanup for sharing

This copy keeps the completed experiment unchanged. The cleanup covers the
supporting scripts, tests and key-configuration helper, not the frozen runtime.

## Changes

- Expanded compressed Python statements and standardised formatting with Black.
- Shortened redundant comments and corrected an inaccurate reference-formatting
  comment. Methodological limitations and AI-assistance disclosures are retained.
- Fixed the HTML exporter so it reads saved outputs without rewriting the notebook
  or replacing its text. A regression test checks this behaviour.
- Replaced a machine-specific Matplotlib cache path with a project-local default
  while respecting an existing `MPLCONFIGDIR` setting.
- Excluded local build files, environment files, macOS metadata and generated ZIPs
  from Git. The submission exporter also excludes macOS metadata.
- Updated packaging to refresh the current file manifest.

## Provenance

`src/`, `config/`, `PROTOCOL.md`, recorded outputs, the supplied notebook and
manuscript files are preserved. The frozen evaluator remains in
`documentation/frozen_source/evaluate.py`. Formatting deliberately excludes these
historical sources because their byte hashes form part of the audit trail.

`documentation/audit_history/FILE_MANIFEST_before_code_cleanup.json` preserves the
incoming package manifest. `FILE_MANIFEST.json` describes the cleaned package;
it is generated by `python scripts/package_submission.py`. Neither manifest
includes its own hash. Earlier submission-verification documents describe the
earlier submission, not this code cleanup.

## Checking this copy

Use the pinned requirements and the offline commands in the main README.
The extra exporter test needs only the Python standard library. With Black
26.5.1 installed, check formatting with:

```bash
python -m black --check scripts tests configure_personal_key.py
```

The CSV is excluded because its redistribution licence is unresolved. No API
key is needed for offline evaluation, and no new model responses are generated.

## Validation performed

- All 19 unit tests passed using Python 3.12 and the pinned requirements.
- All 16 supporting Python files passed Black's formatting check and compilation.
- Independent evidence verification reproduced all 198 task scores and reconciled
  583 recorded experiment responses, 385 tool calls and 69 saved chart files.
- The offline notebook completed all 12 code cells in a separate temporary copy.
  The standard-library HTML exporter also completed; `nbconvert` is optional and
  was not installed in the test environment.
- All 321 original files under `src`, `config`, `outputs`, `notebooks`, `thesis`
  and `submission` were byte-identical, excluding macOS directory metadata.

  not replace the author's review of personal information before publication.

The original download directory was not modified. No fresh API experiment was run.
